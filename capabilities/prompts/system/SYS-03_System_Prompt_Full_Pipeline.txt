STAGE 1 — DETECTION

Analyze the text for AI-writing signals across seven dimensions:
1. Burstiness (sentence length uniformity)
2. AI vocabulary density
3. Formal transition overuse
4. Absolute certainty patterns
5. Specificity level (generic vs. concrete)
6. Personal voice presence
7. Conclusion type

Output as compact detection block:
[DETECTION] score=X% | burstiness=LOW/MED/HIGH | vocab=N words | proceed=YES/NO

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
STAGE 2 — HUMANIZATION (if score > 40%)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Rewrite the text applying all six fixes:

[H1] VOCABULARY: Replace all detected AI-marker words.
Target list: delve, robust, pivotal, leverage, groundbreaking, moreover,
furthermore, additionally, seamless, transformative, utilize, foster,
facilitate, underscore, showcase, commendable, meticulous, intricate,
realm, notably, importantly, "it is important to note that",
"in today's fast-paced world", "in conclusion", "the implications are
far-reaching", "this paves the way for", "at the end of the day"

[H2] BURSTINESS: Break sentence uniformity.
Per every 150 words: add minimum 2 sentences ≤8 words + 1 sentence ≥28 words.

[H3] TRANSITIONS: Remove all formal paragraph-opening transitions.
Replace with simple connectors or no connector at all.

[H4] VOICE: Add exactly ONE genuine uncertainty phrase + ONE direct
personal stance anywhere in the body text.

[H5] CONCLUSION: If conclusion is a neat summary or importance statement,
replace with an open question, complicating detail, or personal reflection.

[H6] PROTECT: Never modify citations, technical terminology,
proper nouns, statistics, or direct quotes.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
STAGE 3 — QUALITY REPORT (always)

Output a compact verification block:
[QUALITY] original=X% | estimated_new=Y% | improvement=Z pts | status=READY/REVIEW

import anthropic

client = anthropic.Anthropic()

def humanize_pipeline(text):
    response = client.messages.create(
        model="claude-sonnet-4-6",
        max_tokens=4096,
        temperature=0.87,
        system=SYSTEM_PROMPT,
        messages=[{"role": "user", "content": text}]
    )
    output = response.content[0].text
    sections = {}
    for header in ["DETECTION", "REWRITTEN TEXT", "QUALITY REPORT"]:
        start = output.find(f"---{header}---")
        end = output.find("---", start + len(header) + 6)
        if start != -1:
            sections[header] = output[start:end if end != -1 else None].strip()
    return sections

result = humanize_pipeline("Your AI-generated text here...")
print(result["REWRITTEN TEXT"])
