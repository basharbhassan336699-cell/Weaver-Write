# الاستشهاد الدقيق برقم الصفحة — دليل الاستخدام

## المشكلة والحل

**المشكلة:** PaperQA2 الأصلية تستشهد بـ `chunk 3` (رقم مقطع) وليس رقم صفحة حقيقي.

**الحل:** `paperqa_pages.py` يستخدم **PyMuPDF4LLM** لاستخراج النص صفحةً صفحةً مع رقمها الحقيقي، ثم يُمرّره لـ PaperQA2 عبر واجهتها الرسمية `aadd_texts` — بلا تعديل أي كود أصلي.

النتيجة: استشهاد `(الأحمد2024، ص. 5)` بدل `(chunk 3)`.

---

## التثبيت

```bash
# الأساس
pip install -e .

# للاستشهاد الدقيق برقم الصفحة
pip install pymupdf4llm

# للـ OCR (ملفات ممسوحة) — PyMuPDF4LLM يشغّله تلقائياً
apt install tesseract-ocr tesseract-ocr-ara   # Termux/Ubuntu
```

## الاستخدام

### Python
```python
from paperqa_pages import PagedPaperQA

qa = PagedPaperQA(lang="arabic")   # أو "english"

# مرجع محلي مع بيانات المؤلف
await qa.add("دراسة.pdf", author="الأحمد", year=2024)

# من الإنترنت
await qa.add("https://arxiv.org/pdf/2409.13740")

# DOI
await qa.add("10.1145/3767695.3769505")

# السؤال — الإجابة تحوي رقم الصفحة
result = await qa.ask("ما النتائج الرئيسية؟")
print(result.answer)
# "...النتيجة الأولى (الأحمد2024، ص. 5)، والثانية (الأحمد2024، ص. 8)..."

# اقتباس حرفي مع رقم الصفحة
result = await qa.ask("اقتبس تعريف المفهوم", verbatim=True)
# "«النص الحرفي» (الأحمد2024، ص. 12)"
```

### سطر الأوامر
```bash
# محلي
python paperqa_pages.py -f study.pdf --author "الأحمد" --year 2024 -q "ما النتائج؟"

# إنترنت
python paperqa_pages.py -u https://arxiv.org/pdf/2409.13740 -q "What is the method?"

# DOI
python paperqa_pages.py --doi 10.1145/3767695.3769505 -q "ما المساهمة؟"

# مجلد كامل
python paperqa_pages.py -d ./papers -q "قارن بين النتائج" --lang arabic

# اقتباس حرفي
python paperqa_pages.py -f study.pdf -q "اقتبس التعريف" --verbatim
```

## ما يعمل مع الإنترنت

| المصدر | الحالة |
|---|---|
| arXiv PDF مباشر | ✅ |
| ResearchGate مجاني | ✅ |
| DOI (عبر doi.org) | ✅ |
| PubMed Central | ✅ |
| مجلات مدفوعة (Elsevier, Springer) | ❌ تحتاج PDF يدوياً |
| PDF محمي بكلمة مرور | ❌ |

## كيف يحفظ رقم الصفحة (تقنياً)

```
PDF → PyMuPDF4LLM (page_chunks=True)
    → كل صفحة: {text, metadata.page_number}
    → Text(name="الأحمد2024، ص. 5", text=..., doc=...)
    → docs.aadd_texts(texts, doc)   ← واجهة PaperQA الرسمية
    → عند الإجابة: name يظهر في الاستشهاد
```

اسم المقطع (`Text.name`) هو ما يظهر في استشهاد PaperQA2 — فبجعله يحوي رقم الصفحة، يصبح الاستشهاد دقيقاً تلقائياً بلا تعديل منطق PaperQA2.
